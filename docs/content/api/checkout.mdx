# Checkout API

Create hosted payment sessions. Afriex handles the payment UI; you redirect customers to complete the transaction.

## Create Checkout Session

```typescript
const session = await afriex.checkout.createSession({
  customer: {
    fullName: "John Doe",
    email: "john@example.com",
    phone: "+1234567890",
    countryCode: "US",
  },
  transaction: {
    sourceAmount: "100.00",
    sourceCurrency: "USD",
    destinationAmount: "75000.00",
    destinationCurrency: "NGN",
    type: "WITHDRAW",
    destinationId: "payment-method-id",
    meta: {
      idempotencyKey: "unique-session-123",
      reference: "order-456",
      narration: "Payment for order #456",
    },
  },
  successUrl: "https://yourapp.com/success",
  cancelUrl: "https://yourapp.com/cancel",
  webhookUrl: "https://yourapp.com/webhook", // Optional
});

// Redirect customer to session.checkoutUrl
console.log(session.checkoutUrl); // https://checkout.afriex.com/...
```

**Response:**

```typescript
{
  checkoutId: string;
  checkoutUrl: string; // Redirect customer here
  expiresAt: string; // ISO 8601 timestamp
}
```

## Parameters

| Field                             | Type     | Required           | Description                                        |
| :-------------------------------- | :------- | :----------------- | :------------------------------------------------- |
| `customer.fullName`               | `string` | Yes                | Customer's full name                               |
| `customer.email`                  | `string` | Yes                | Customer's email address                           |
| `customer.phone`                  | `string` | Yes                | Phone number with country code                     |
| `customer.countryCode`            | `string` | Yes                | ISO 3166-1 alpha-2 code                            |
| `transaction.sourceAmount`        | `string` | Yes                | Amount debited in source currency                  |
| `transaction.sourceCurrency`      | `string` | Yes                | Source currency code (e.g., `USD`)                 |
| `transaction.destinationAmount`   | `string` | Yes                | Amount credited in destination currency            |
| `transaction.destinationCurrency` | `string` | Yes                | Destination currency code (e.g., `NGN`)            |
| `transaction.type`                | `string` | -                  | `WITHDRAW` (default), `DEPOSIT`, or `SWAP`         |
| `transaction.destinationId`       | `string` | Yes for `WITHDRAW` | Payment method to send funds to                    |
| `transaction.sourceId`            | `string` | Yes for `DEPOSIT`  | Payment method to pull funds from                  |
| `transaction.meta.idempotencyKey` | `string` | Yes                | Unique key to prevent duplicate sessions           |
| `transaction.meta.reference`      | `string` | Yes                | Your internal reference (order ID, invoice number) |
| `transaction.meta.narration`      | `string` | -                  | Transaction description shown to customer          |
| `successUrl`                      | `string` | Yes                | Redirect URL after successful payment              |
| `cancelUrl`                       | `string` | Yes                | Redirect URL if customer cancels                   |
| `webhookUrl`                      | `string` | -                  | Webhook endpoint for transaction updates           |

## Session Flow

1. **Create session** with customer and transaction details
2. **Redirect customer** to `checkoutUrl`
3. **Customer completes payment** on Afriex-hosted page
4. **Afriex redirects** to `successUrl` or `cancelUrl`
5. **Receive webhook** with final transaction status (if `webhookUrl` provided)

## Use Cases

**Immediate payment collection**  
Customer pays now; funds settle to your balance.

**Delayed payment processing**  
Create session in advance; send link to customer later.

**Embedded checkout**  
Open `checkoutUrl` in iframe or webview for in-app payment.
